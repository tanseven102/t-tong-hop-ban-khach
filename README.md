## Cài đặt

1. Giải nén file zip ra một thư mục (vd `D:\T-TONG HOP`).
2. Bấm đúp **T-TONG HOP.exe**. Windows hỏi "Không rõ nhà phát hành" → *Thông tin thêm* → *Vẫn chạy*.
3. Tool hiện **MÃ MÁY**. Chuyển khoản gói đã chọn và gửi MÃ MÁY qua Zalo Tân Seven → nhận **KEY** → dán vào, bấm **KÍCH HOẠT**.
4. Mở `api_key.txt`, dán khoá OpenAI của bạn (bắt đầu bằng `sk-`).
